# SCP Reader 简体中文汉化版 · v1.4.1-zh.3

**本次更新重点修复中文检索和筛选不刷新的问题。**

## 修复
- 修正 CROM GraphQL 中文分部请求：`anyBaseUrl` 使用正确的数组格式，恢复中文关键词与 SCP 编号查询。
- 首页和检索页各自使用独立的分类筛选，不再发生相互干扰导致搜索结果被过滤掉的情况。
- 未输入关键词时，搜索页的排行会响应筛选条件；选择“故事”或“相关组织”时切换到相应的已选分部排行。
- 请求失败时显示错误和重试入口，避免把服务异常默认为“0 条结果”。
- SCP 编号查询支持索引前缀和对应档案元数据回退，降低漏检概率。

## 验证
- Android Gradle Debug APK 构建通过。
- GitHub Actions 对 CROM 进行了真实查询（包括应用实际使用的完整字段）：中文关键词“记忆删除”返回 5 条，编号“173”返回 1 条，均无 GraphQL 错误。
- 仍建议用户在自己的网络环境下使用 SCP-CN 单分部检查关键词、筛选和跳转。

## 安装与更新
- 已安装 `v1.4.1-zh.2` 正式版的用户：使用**同一永久签名**，可以正常覆盖升级，或从应用内检查更新。
- 安装 `v1.4.1-zh.1` 预览版或 Debug 包的用户：签名/包名不同，升级前请备份重要数据，按安装提示处理。
- 最低 Android 7.0。
