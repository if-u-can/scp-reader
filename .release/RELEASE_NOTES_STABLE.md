# SCP Reader 简体中文汉化版 · v1.4.1-zh.4

**本版新增阅读界面的简繁转换功能。**

## 新功能
- 在档案阅读页顶栏点击「简 / 繁 / 原」按钮，选择 **简体中文、繁體中文、原文**。
- 首次使用默认「简体中文」；选择后会记住，下次打开阅读器仍按该模式显示。
- 按词组规则转换正文中的段落、标题、脚注、表格、折叠内容、标签页与图片说明，并同步调整阅读页标题。
- 显示转换**不修改** SCP 编号、维基链接、已下载的档案原文，也不改变维基分部选择、搜索来源或离线缓存。
- 如有专有名词转换不理想，可切换「原文」随时核对原始内容。繁简转换并非翻译，但多义字和个别术语仍可能产生歧义。

## 验证
- Android Debug 构建成功，单独运行 ReaderScriptConverterTest 测试通过。
- OpenCC4J 1.14.0（Apache-2.0）提供离线词组级繁简字转换；无需任何网络服务。
- 之前的中文检索和筛选修复均保留。

## 安装与升级
本 Release 使用与 `v1.4.1-zh.2`、`v1.4.1-zh.3` **相同的固定正式签名**，这两个正式版可直接覆盖升级，也可通过应用内更新检查安装新版。

如果安装的是最早的 `v1.4.1-zh.1` 预览版或 Debug 测试包，签名/包名可能不同；请注意备份数据，按安装提示处理。最低 Android 7.0。
