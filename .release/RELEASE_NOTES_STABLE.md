# SCP Reader 简体中文汉化版 · 首个固定签名正式版

本项目是基于 [ThePixelPro366/scp-reader](https://github.com/ThePixelPro366/scp-reader) 的**非官方简体中文汉化版**。

**控制，收容，保护**

## 功能

- 简体中文界面及基金会惯用术语；
- 保留原版的多语言分部多选和搜索、档案阅读、离线下载、音频功能；
- 普通档案检索、故事、相关组织和系列使用所选分部作为数据来源；
- 评分榜参考英文主站排行，优先展示已选分部实际存在的对应档案，不虚构翻译；
- 基于原版 Material 3 外观和其它原有功能。

## 安装和更新

下载本 Release 的 `*.apk`，在 Android 7.0 及以上安装。本版本开始采用**固定、专属的正式签名密钥**，后续同签名版本可覆盖安装。

> **从 v1.4.1-zh.1 预览版升级的用户请注意：** 之前的预览 APK 使用临时签名，**无法直接覆盖升级到首个正式版**。请先备份重要数据、卸载预览版、重新安装正式版。之后只要继续使用相同签名，便可正常升级。
